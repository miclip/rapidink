# RapidInk Product Guide

## Vision

RapidInk is a free, open-source web application that generates fully customizable, hyperlinked PDF planners optimized for digital note-taking devices. Unlike static planner PDFs that force users into a one-size-fits-all structure, RapidInk empowers bullet journaling enthusiasts to create planners tailored to their exact workflow and preferences.

## Target Users

**Primary Audience:** Bullet journaling enthusiasts who use digital note-taking devices such as:
- reMarkable 1, 2, and Paper Pro
- Supernote A5X, A6X, and Nomad
- Kindle Scribe
- Boox Note Air, Tab Ultra, and Note Max
- iPad with GoodNotes, Notability, or similar apps

These users value the tactile experience of handwriting combined with the organizational power of hyperlinked digital documents. They want planners that function as "document-based applications" with rich navigation.

## Core Differentiators

### 1. Full Customization
Users control every aspect of their planner:
- Enable/disable sections (cover, index, guide, goals, future log, habit tracker, collections)
- Configure daily page layouts (freeform, time-blocked, split, schedule)
- Choose visual styles (dot grid, lines, blank, grid patterns)
- Set custom navigation links that appear on every page
- Define habits to track and collections to include

### 2. Year-Aware Calendar
Unlike traditional planners that show only "1, 2, 3..." for dates, RapidInk displays the day of week alongside the date using single-letter abbreviations (e.g., "1 M", "2 T", "3 W"). This eliminates the need to manually annotate each day and provides immediate context for planning.

### 3. Enhanced Navigation
Every page includes configurable quick-navigation links, not just the index and monthly overview. Users can jump directly to:
- Index, Month, Week views
- Intentions, Goals, Habits sections
- Custom collections

This creates a true "document-based application" experience on devices that lack native app ecosystems.

## Key Features

- **Multi-Device Support:** Presets for 15+ devices with correct dimensions, DPI, and toolbar offsets
- **iCal Import:** Import calendar events from .ics files to pre-populate daily pages
- **Config Persistence:** Configuration embedded in generated PDFs for easy re-use and iteration
- **Visual Customization:** Dot spacing, size, opacity, font size all configurable
- **Reflection Prompts:** Weekly and monthly reflection sections with customizable prompts
- **Write-in Slots:** Blank collection slots for adding new sections on-device

## Distribution Model

RapidInk is a free, open-source project:
- Hosted on GitHub Pages for immediate access
- Full source code available under open-source license
- No server required - runs entirely in the browser
- Users can self-host if desired
